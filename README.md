# AI Requirements Validator

Командный репозиторий для хакатона **BCC-HUB x MNU FinTech Hackathon** — https://bcchubagents.mnu.kz/

Задание организаторов: https://github.com/BCC-HUB/ai-requirements-validator-task

## Задача (кратко)
ИИ-агент, который проводит статическую проверку документа с требованиями (`docs/requirements.md` от организаторов): выделяет отдельные требования, оценивает каждое и весь набор по критериям качества (ISO/IEC/IEEE 29148:2018 п. 5.2.5–5.2.6, IEEE Std 830-1998 п. 4.3) и записывает отчёт в файл.

## Структура
- `docs/` — входной документ требований от организаторов
- `reports/` — отчёты, сформированные агентом
- код агента — структуру определяем командой

- [ ] Итог: можно ли начинать разработку/тестирование и что исправить в первую очередь
- [ ] Каждое нарушение ссылается на конкретное место в документе

## Как работаем
1. `main` всегда рабочий — напрямую в него не пушим.
2. Перед работой: `git pull origin main`
3. Своя ветка: `git checkout -b feature/название`
4. Коммитим часто, пушим: `git push origin feature/название`
5. Открываем Pull Request в `main`, кто-то из команды смотрит и мёржит.
6. Ключи — только в `.env` (он в `.gitignore`).
7. Задачи ведём в GitHub Issues.
