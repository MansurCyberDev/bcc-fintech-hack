# BCC Fintech Hack

Проект команды на финтех-хакатоне MNU × BCC Hub.

## Структура
- `frontend/` — интерфейс (веб/мобильный)
- `backend/` — API, база данных, бизнес-логика
- `bot/` — AI, интеграции, Telegram-бот, n8n

Каждый работает в своей папке и не трогает чужие без договорённости.

## Как работаем
1. `main` всегда рабочий — напрямую в него не пушим.
2. Перед работой: `git pull origin main`
3. Своя ветка: `git checkout -b feature/название`
4. Коммитим часто, пушим: `git push origin feature/название`
5. Открываем Pull Request в `main`, кто-то из команды смотрит и мёржит.
6. Секреты — только в `.env` (он в `.gitignore`). Пример переменных — в `.env.example`.
