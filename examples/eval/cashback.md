# Кешбэк за покупки в категории «Кафе и рестораны»

## Часть A. Бизнес-требования

### Цель
Повысить активность клиентов по дебетовым картам за счёт кешбэка в кафе и ресторанах.

### Функциональные требования
* **КБ-1.** Клиент с дебетовой картой подключает кешбэк в приложении. Кешбэк составляет 5% от суммы покупки в категории «Кафе и рестораны».
* **КБ-2.** Кешбэк начисляется за покупки, совершённые после подключения. Начисление происходит в последний день месяца.
* **КБ-3.** Максимальный кешбэк — 10 000 ₸ в месяц. Кешбэк, превышающий лимит, переносится на следующий месяц.
* **КБ-4.** Если сумма кешбэка за месяц превышает лимит, начисление за месяц не производится.
* **КБ-5.** Система должна быстро показывать клиенту накопленный кешбэк.
* **КБ-6.** Категория покупки определяется по MCC торговой точки.

### Нефункциональные требования
Экран кешбэка открывается удобно для пользователя.

### Требования к данным
Хранить идентификатор клиента, сумму покупки в тенге, сумму кешбэка в тиынах и дату начисления.

### Критерии приемки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| Кешбэк подключен, покупка в кафе на 2 000 ₸ | Провести покупку | Начислено 200 ₸ |
| Накоплено 9 900 ₸ кешбэка | Покупка в ресторане на 4 000 ₸ | Начислено 100 ₸, остальное переносится |

## Часть B. REST API

### Метод подключения кешбэка

| Поле | Значение |
| :--- | :--- |
| Description | Подключение кешбэка |
| REST type | GET |
| Request URL | /cashback/enable |

#### Параметры запроса

| Параметр | Тип | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| clientId | integer | Да | Идентификатор клиента |
| percent | integer | Да | Процент кешбэка |

#### Ответ

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| clientId | string | Идентификатор клиента |
| status | string | ENABLED и т.д. |

#### 200. Successful
Кешбэк подключен.
