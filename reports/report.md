#### D-02 🔴 Метод GET для операции изменения данных

*Критично · Корректность (ISO 29148 5.2.5 h; IEEE 830 4.3.1) · требования: R-18, R-22 · найдено: правило + LLM*

В спецификации API указано сохранение настроек через метод GET, что нарушает стандарты REST API (методы GET должны быть безопасными и идемпотентными) и противоречит логике изменения состояния системы.

#### D-02 🔴 Метод GET для операции изменения данных

*Критично · Корректность (ISO 29148 5.2.5 h; IEEE 830 4.3.1) · требования: R-18, R-22 · найдено: правило + LLM*

В спецификации API указано сохранение настроек через метод GET, что нарушает стандарты REST API (методы GET должны быть безопасными и идемпотентными) и противоречит логике изменения состояния системы.

**Как исправить.** Использовать PUT (замена настройки) или POST, параметры передавать в теле JSON.
