# CLAUDE.md — контекст проекта

Хакатон BCC-HUB x MNU FinTech: ИИ-агент статической проверки документа с требованиями.
Задание: https://github.com/BCC-HUB/ai-requirements-validator-task (README + docs/requirements.md).
Сдача: демо + репозиторий до 27.11.2026 23:59 (Астана). Жюри (по 25%): уточняющие вопросы, архитектура агентов,
ценность продукта, презентация. Команда — 3 студента первого курса: код должен оставаться простым.

## Обязательно (из ТЗ)
- Запуск одной командой: `python main.py <документ> <отчёт>`; вход PDF (+ md, docx, txt).
- Отчёт на русском: паспорт (документ, дата, модель, версия агента), нарезка (ID отчёта — ID документа — формулировка),
  проверка каждого требования, проверка набора, сводка, итог. Каждое нарушение — со ссылкой на место (цитата + строка).
- Критерии: ISO/IEC/IEEE 29148:2018 п. 5.2.5–5.2.6, IEEE 830-1998 п. 4.3.
- Секреты только в `.env`; в корне `.env.example`. README: ключ, запуск, где отчёт.
- Отчёт для сдачи генерирует только агент. Вручную не править.

## Правила разработки
- Никаких ответов, «зашитых» под документ организаторов: правила и промпты общие.
- Каждое замечание LLM проходит проверку цитаты кодом (src/verify.py). Не ослаблять.
- Без ключа агент должен работать (режим «только правила») и честно писать это в паспорте.
- Перед коммитом: `python -m pytest -q`.
- `main` не трогаем напрямую: ветка + Pull Request.
