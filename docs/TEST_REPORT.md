# Отчёт о тестировании

Дата: 2026-11-25. Ветка `feature/validator-agent`.

## 1. Автотесты (pytest)

Команда: `python -m pytest -q` → **39 passed** (облачная среда Linux, Python 3).

| Файл | Что проверяет |
| :--- | :--- |
| `test_ingest.py` | чтение md, txt (utf-8 и cp1251), docx, pdf; восстановление заголовков и таблиц в PDF |
| `test_split.py` | нарезка на требования, ID из документа, свои ID, номера строк |
| `test_rules.py` | правила: размытые слова, заглушки, HTTP-семантика, единицы, версия и др. |
| `test_verify.py` | проверка цитат кодом: точное, по частям, нечёткое совпадение; выдуманная цитата отбрасывается |
| `test_llm_client.py` | повторы при 429/503, неверный ключ без повторов, лимит вызовов, OpenAI-совместимый API, дневная квота (быстрый отказ), запасная модель при 404 и 503, починка и «спасение» обрезанного JSON |
| `test_merge.py` | слияние дублей «правило + LLM» про одно место и одну тему; разные места не сливаются |
| `test_pipeline.py` | полный прогон с поддельной LLM; деградация при сбое LLM; честный режим в паспорте, если LLM не ответила |
| `test_cli.py` | запуск одной командой, режим `--offline`, коды выхода |
| `test_security.py` | экранирование HTML (XSS) и защита от prompt injection |

## 3. Реальные вызовы Gemini (ноутбук команды, бесплатный ключ)

Ключ лежал только в `.env` на ноутбуке и в репозиторий не попадал.

### Прогон 1 (коммит 4c1983e-dirty), `docs/requirements.md`

- Модель: `gemini-flash-lite-latest` (основная `gemini-flash-latest` упёрлась в дневную квоту бесплатного ключа, HTTP 429).
- Время 83 с, 13 вызовов LLM.
- 39 дефектов (🔴 5, 🟠 22, 🟡 12), 12 уточняющих вопросов.
- 4 замечания LLM отброшены: код не нашёл их цитату в документе. 2 дубля слиты, 1 замечание отклонил критик.
- 1 ошибка LLM: пачка 4/4 вернула невалидный JSON, а запрос на починку получил 503.
- Вердикт: начинать разработку нельзя.

Найденные проблемы и исправления (коммит 4462465):
- дубли «правило + LLM» про одно место сливались не всегда → `_similar` сравнивает темы заголовков;
- обрезанный JSON выбрасывался целиком → `_salvage` сохраняет целые объекты;
- `docs/REQUIREMENTS.md` и `docs/requirements.md` конфликтовали на macOS → матрица переименована в `docs/REQUIREMENTS_MATRIX.md`.

PDF-прогон: 214 с, модель часто отвечала 503, и агент доделал отчёт правилами, о чём честно написал в паспорте.

## 4. Ручные и браузерные проверки

- Веб-интерфейс `python web.py`: загрузка документа, страница задачи, отчёт HTML/MD/JSON, отправка ответов автора (Playwright, Chromium).
- HTML-отчёт: тёмная тема, навигация, широкие таблицы прокручиваются, на ширине телефона нет горизонтальной прокрутки страницы.

## 5. Известные ограничения

- Бесплатный ключ Gemini: дневная квота и частые 503 у новых моделей. Агент переключается на запасную модель, а если LLM недоступна, доделывает отчёт правилами.
- Результаты LLM немного отличаются между прогонами. Правила детерминированы.

## 6. Оценка качества (сверка с эталоном)

### Документ организаторов против эталона из 24 дефектов (`gemini-flash-lite-latest`)
Отчёт в `reports/report.md`: полностью найдено 11, частично 4, пропущено 9.
Главные пропуски — два противоречия: Ф-2 против критерия приёмки (к какому месяцу относится покупка около полуночи) и Ф-3 против Ф-4 (второй push после смены порога). Также не найдены: нет метода чтения настроек и идемпотентность событий.
Ложные и слабые замечания LLM в первом прогоне: 4–5 (например, мнимая «опечатка»).

После изменения промптов (пошаговая проверка набора, строже критик) прошёл один прогон, где проверка набора выполнилась (коммит d45a33c): 25 дефектов, придирки ушли, тема GET слилась в одно замечание. Два главных противоречия облегчённая модель всё равно не нашла, и одно новое замечание уровня набора ложное (про критерий с переводом). Вывод: для смысловых противоречий нужна более сильная модель.

Прогон команды на `gemini-3.6-flash` (коммит 27ff198, все шаги LLM выполнены, ~198 с): 30 дефектов (🔴 6). Найдены противоречие Ф-2 и критерия приёмки (месяц покупки около полуночи) и отсутствие методов чтения настроек; новые замечания по делу (возврат и повторный push, снижение порога ниже текущих расходов). Полностью найдено около 13 из 24 эталонных. Всё ещё не найдены: Ф-3 против Ф-4, идемпотентность событий. Тема «200 при ошибке» разбита на несколько замечаний. После этого агент по умолчанию предпочитает полноценные Flash-модели облегчённым.

### Новый документ `examples/eval/cashback.md` (15 заложенных дефектов, эталон в `cashback_key.md`)
- Только правила: 9 из 15.
- Правила + LLM (проверка набора не выполнилась из-за 503): 12 из 15, ложных срабатываний нет. Найдены оба противоречия (перенос против «начисления нет», 5% от 2 000 ₸ ≠ 200 ₸) и передача процента клиентом. Пропущены: начисление сразу против «в конце месяца», нет методов отключения и чтения, возвраты.

### Квоты
Бесплатный ключ Gemini за день исчерпал квоту большинства моделей. Добавлено: быстрое переключение модели при 503, свой учёт квоты для каждой модели, подбор моделей из списка, доступного ключу, и несколько ключей (`GEMINI_API_KEYS`).
