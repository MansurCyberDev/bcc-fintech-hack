# Прогресс

## Сделано
- Конвейер: чтение (md/pdf/docx/txt) → нарезка → правила → LLM-аналитик → проверка цитат кодом → слияние дублей → критик → уточняющие вопросы и ответы → вердикт → отчёт MD/HTML/JSON.
- CLI одной командой, режимы `--offline`, `-i`, `--answers`; веб-интерфейс для демо.
- Устойчивость LLM: повторы, запасная модель, быстрый отказ при дневной квоте, «предохранитель», честный режим в паспорте.
- 39 автотестов проходят. Реальный прогон с Gemini на ноутбуке выполнен (см. docs/TEST_REPORT.md).
- Отчёты агента по документу организаторов (md и pdf, реальный Gemini) лежат в `reports/`.
